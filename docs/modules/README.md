# Modules

Each module has a doc here, named after its folder in `src/modules/`. Start a doc when the idea comes up, and update its status as it moves along.

| Status | Meaning |
|---|---|
| `idea` | Worth exploring, not designed yet |
| `planned` | Design agreed, not started |
| `building` | In progress |
| `done` | Built and in use |
